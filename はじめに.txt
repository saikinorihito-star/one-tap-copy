ワンタップコピー（iPhone向けウェブアプリ）バージョン2

■ できること
- 登録した文章をタップしてコピー。コピーが成功するとコピー回数を記録します。
- 全件表示・検索語なしの状態で「↕ 並べ替え」を押すと「↑ 上へ」「↓ 下へ」で好きな順に並べ替えできます（自動保存）。
- カテゴリーごとにカードの左端、ラベル、カテゴリータブを色分けします。「⚙ 設定・バックアップ → カテゴリーの色を変更」から色を選べます。
- タイトル・本文・カテゴリーの登録、編集、削除確認、検索、お気に入り登録。
- JSONバックアップの書き出し・復元。新しいバックアップには並び順、色の設定、コピー回数も含まれます。初期版のバックアップも読み込めます。

■ Mac と GitHub での新規導入
1. ZIPを展開し、one_tap_copy_app フォルダーを開きます。
2. GitHubで新しいPublicリポジトリを作り、フォルダー内のファイルをすべてリポジトリ直下にアップロードしてコミットします。
3. GitHubのリポジトリの Settings → Pages → Build and deployment → Deploy from a branch を選択。
   Branchを main、フォルダーを /(root) として保存します。
4. GitHub Pagesの公開URL（https://ユーザー名.github.io/リポジトリ名/）をiPhoneのSafariで開きます。
5. Safariの共有メニューから「ホーム画面に追加」を選び「ウェブアプリとして開く」をオンにします。
6. ホーム画面に追加したアプリを開いて、文章を登録します。

■ 初期版から更新する場合
- 念のため、初期版で先にJSONバックアップを保存してください。
- 既存のGitHubリポジトリ内の index.html と sw.js を今回のファイルに更新してください。アイコンとmanifest.webmanifestはそのままでも使えます。
- 更新後にiPhoneのアプリを完全に終了して開き直してください。配信反映やキャッシュの更新に時間がかかる場合はSafariで公開URLを再読み込みしてください。
- 登録済みの文章は同じ保存領域・同じ保存キーを使用するため基本的には引き継がれます（ブラウザのデータ消去などをしていない場合）。

■ 注意
- 最初の文章登録はホーム画面のアプリ内で行ってください。Safariで開いたページとホーム画面アプリでは保存領域が独立する場合があります。
- 登録データ（文章、順序、色設定、コピー回数）は端末内に保存し、別端末との自動同期はしません。アプリ削除やデータ消去で消えることがあるため、定期的にJSONバックアップを保管してください。
- アプリのソースコードはPublicリポジトリに公開されます。登録した文章はプログラムのファイルには含まれません。
- パスワード、認証コード、機密情報は登録しないでください。
- コピー回数はこのアプリ内で成功したコピーのみを数えます。他のアプリでコピーした回数は分かりません。
- HTTPSの公開URLで使ってください（GitHub Pagesが提供します）。iPhone実機での動作は未確認です。
